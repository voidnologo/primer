Point it at anything

The intake interview discovers what you already know and decomposes the goal you actually have. There is no built-in curriculum to fit into, so the subject is yours to choose.

/primer plate tectonics /primer how cats regulate body heat /primer orbital resonance /primer combat math for my RPG /primer Italian subjunctive /primer consistent hashing /primer wine fermentation /primer counterpoint

The figure above is from a geology lesson. The same diagram forms draw a protocol handshake, a stellar lifecycle, or an initiative order — because they describe shapes of ideas, not a field.

Named for the book you wish you'd had

In Neal Stephenson's The Diamond Age, the Young Lady's Illustrated Primer is a book that notices who's reading it and reshapes itself to fit. It meets its reader where she is and grows alongside her, never pitched over her head or beneath it.

That's the north star, aimed at a smaller and stubbornly real problem: staying sharp in a field that reinvents itself every eighteen months. No fairy tale. But a tutor that knows your depth, teaches when you tug a thread rather than when a syllabus says so, and leaves you lessons you keep: that part is reproducible, and that is what it chases.

What makes it different

Each of these is a constraint the engine enforces in code, rather than an aspiration in a README.

It knows what it knows

Depth markers carry confidence and evidence. primer distinguishes what it has watched you do from what it inferred, and decays both over time. It will not hand you a certain-looking guess about yourself.

You predict first

Diagrams arrive with the causal step blanked. You commit to an answer before the reveal is reachable. Generating an idea beats being handed one, so the page will not let you be handed one.

Never quietly stale

Every lesson runs a source-discovery pass and records its verdicts. The built-in canon is a vetted floor rather than a ceiling, so knowledge doesn't freeze on the day someone wrote a list.

Private by architecture

Your profile and your lessons live only in your own private repo. The public engine holds zero personal data, and the skill never goes digging through your own files.

Get started

Install it, then let the interview do the work. It discovers your depth instead of assuming a curriculum.

1

Clone the engine and install it as a skill.

git clone https://github.com/voidnologo/primer
cd primer && ./tools/install.sh
2

In any Claude Code session, run the one-time setup. It scaffolds your private data repo, then runs the cold-start interview.

/primer init
3

Learn something.

/primer plate tectonics
/primer nextwhat to learn next
/primer reviewspaced-retrieval warm-up
/primer viewopen a lesson's figures
/primer indexyour topic map, with status
/primer recalibratedeep profile review
/primer updateengine + instance, one step
What you need. Claude Code in a local session: the terminal CLI, or the Code tab of the desktop app. That part is technical. What you point it at is not — primer reads your local skills and writes to a private git repo you own, so cloud and Cowork sessions can't reach it. Nothing else is required: no server, no account, no third-party service.
